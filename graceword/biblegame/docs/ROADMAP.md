## 3. 已交付里程碑

### M1：可玩的每日 MVP

- 5 題每日挑戰、四選一、年代與地理雙軸計分。
- 放大鏡、答錯提示、結算頁。
- 內嵌地圖與響應式版面。

### M2：內容與雙語

- 6 個新約故事、30 題、30 張公版畫作。
- CUV／WEB 經文、30 則藝術知識、30 則地理知識。
- 中英雙語、雙根布局、SEO metadata、sitemap。

### M3：留存與學習

- `/stories/` 故事庫、完成／練習／鎖定狀態。
- `/progress/` 連闖、最佳分、最近 7 天、8 枚徽章。
- `/places/` 地名對照學習頁（noindex）。
- 故事旅程地圖與五幕回顧。

### M4：朋友挑戰

- 從已完成故事抽 5 題發起挑戰。
- 帶分數 token 與朋友成績比較。
- 每日故事／混合題結算頁可直接分享當天 5 題。
- 舊 token 相容、非法 token 處理。

### M5：測試站部署

- 靜態輸出、子路徑、CDN 圖片、Nginx、Cloudflare。
- 建置後 `check:export` 雙語／SEO 檢查。
- 200 項測試與部署後人工驗收。

## 5. 下一階段：0.2 內容與留存

優先做「不用後端也能完成」的功能。

### 5.1 內容擴充

- 目標：12 個故事／60 題以上。
- 優先補新約比喻、醫治、宣教旅程；再評估舊約與教會歷史。
- 每個故事維持 5 幕、5 題、雙語、經文、藝術知識、地理知識。
- 建立內容檢查清單，避免缺英文、缺經文、缺授權。

### 5.2 硬核模式

- 不顯示區域提示、降低放大倍率、年代容忍區間縮小。
- 獨立標記與徽章；不影響每日基礎分數。
- 驗收：同一題在硬核模式得分較低，且不寫入每日最佳分。

### 5.3 圖鑑收藏

- 已完成故事可看所有畫作、作者、年份、經文與知識。
- 未完成故事只顯示剪影或鎖頭，不洩漏答案。
- 驗收：未完成故事不露出畫作與事件名稱。

### 5.4 季節活動

- 聖誕、受難週、五旬節等期間限定題組。
- 以日期決定活動，不破壞每日故事順序。
- 驗收：活動期間與非活動期間的每日題組都能重現。

## 6. 中長期：0.3 社交與平台

這些項目需要後端或第三方服務，先設計再開發。

### 6.1 經文猜圖（反轉模式）

- 顯示經文與提示，從四幅畫中選出對應事件。
- 可重用現有題庫與計分，但需要新的出題介面。
- 驗收：同一題庫可同時支援「看圖猜事件」與「看經文猜圖」。

### 6.2 PWA／離線

- App shell、題目與圖片快取。
- 每日換題後能更新，不長期顯示舊題。
- 驗收：離線可開啟今日已快取題目；上線後可取得新版本。

### 6.3 房間碼多人

- 主日學／小組破冰：房主開房、朋友輸入房碼、同步同一組題。
- 需要即時後端（WebSocket／Realtime DB／Serverless）。
- 驗收：2–10 人同房、分數即時更新、房主可重開。

### 6.4 帳號與可信排行榜

- 登入、跨裝置同步、伺服器端計分與簽章。
- 需要資料庫、隱私政策、濫用防護。
- 驗收：分數不可由前端篡改；可跨裝置續玩。

### 6.5 內容管理

- 後台或腳本化流程：新增題目、圖片上傳 CDN、經文抓取、雙語缺漏檢查。
- 驗收：新增一題只需填資料與執行一個命令，測試自動把關。

## 7. 優先級與理由

1. **穩定化與正式上線**：目前已有完整閉環，先讓它能穩定對外。
2. **內容擴充**：每日遊戲的留存主要取決於題庫深度；30 題很快會被玩完。
3. **硬核模式與收藏**：不需要後端，能明顯增加重玩動機。
4. **PWA**：提升回訪與移動端體驗，但應在內容穩定後做。
5. **多人與帳號**：價值高但成本最高，等前面驗證留存後再投入。

## 8. 風險與依賴

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 靜態 token 可偽造 | 挑戰成績不可信 | 明確標示；正式競賽改用後端 |
| 題目與答案在前端 | 可被查看 | 接受此限制；不放入敏感內容 |
| localStorage 被清除 | 進度遺失 | 說明用途；未來做帳號同步 |
| CDN 圖片缺失／快取 | 破圖或舊圖 | `SafeImage` 回退、部署後 curl 檢查、Purge |
| 內容授權 | 無法散布 | 只用公版／CC0／CC BY-SA，保留作者與來源 |
| 地圖資料較大 | 首次載入較慢 | 壓縮 GeoJSON、快取、僅載入必要圖層 |
| 無 E2E | 回歸靠人工 | 先補最小 Playwright 流程 |
| 正式站與測試站設定不同 | SEO／資源錯路徑 | 建置前檢查 `NEXT_PUBLIC_SITE_URL`、`BASE_PATH` |

## 10. 建議追蹤指標

目前尚未建立產品儀表板；可用 GA4 事件與伺服器日誌逐步補齊。

| 指標 | 定義 | 用途 |
| --- | --- | --- |
| 每日遊玩數 | 完成至少一題的 session | 基本活躍 |
| 每日完成率 | 完成 5 題／開始遊戲 | 關卡難度與流程 |
| 平均分數 | 每日總分平均 | 難度平衡 |
| 故事完成數 | 完成故事人數／總玩家 | 內容消耗速度 |
| 挑戰分享率 | 分享挑戰／完成每日 | 社交傳播 |
| 挑戰回訪率 | 開挑戰連結後完成 | 分享品質 |
| 次日／七日留存 | 隔日再玩比例 | 長期留存 |
